# Estudos de boas práticas

Esta pasta reúne estudos curtos de boas práticas para análise de mídia, tracking e e-commerce. Eles valem para qualquer demanda desse tipo e não descrevem nenhum caso específico.

As pesquisas foram feitas antes, com subagentes e busca na web (deep research). Cada prática traz a regra, como aplicar e a fonte com link, para você conferir a origem.

## Como usar

Leia os arquivos antes de investigar e antes de montar cada entrega. O plano de cada entrega deve citar a prática que sustenta cada decisão, por exemplo "gráfico de barras, conforme V1". Se uma decisão não tem prática que a sustente, explique o motivo no plano.

## Arquivos

- `caderno_investigacao.md`: o HTML de trabalho usado durante a investigação, com uma seção por hipótese.
- `html_executivo.md`: o relatório executivo para cliente ou comitê, com a resposta primeiro.
- `dash_acompanhamento.md`: a dash de monitoramento, com layout, alertas e a parte técnica de Streamlit.
- `visualizacao_e_design.md`: escolha de gráfico, cor, acessibilidade e formatação em pt-BR.
